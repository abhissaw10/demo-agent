# Exchange Policy

- An exchange request must be raised on or before 3 calendar days from the delivery date.
- The original price tag must still be attached to the item.
- The item must be unused and in the same condition in which it was delivered.
- An item can be exchanged only once.
- After an item has been exchanged once, it can neither be exchanged again nor returned for a refund.
- The requested replacement is subject to inventory availability.
