# Refund Policy

## Delivered items

- An item can be returned for a refund on or before 3 calendar days from its delivery date.
- The original price tag must still be attached to the item.
- The item must be unused and in the same condition in which it was delivered.
- Proof of purchase and the order identifier must be supplied with the request.
- An item that has already been exchanged once cannot subsequently be returned for a refund.

## Orders that have not been delivered

- The maximum delivery service-level agreement (SLA) is 2 weeks (14 calendar days) from the date the order was placed.
- A missing estimated delivery date does not, by itself, make an order eligible for a refund.
- If an order was placed more than 14 calendar days ago, has not been delivered, and still has no estimated delivery date, the customer may apply for cancellation and a refund.
- If the order is still within the 14-day delivery SLA, the customer should be asked to remain patient while we try to deliver it as soon as possible.
- The support team will validate the fulfillment exception before approving the refund.
- Refunds are issued to the original payment method after approval.
